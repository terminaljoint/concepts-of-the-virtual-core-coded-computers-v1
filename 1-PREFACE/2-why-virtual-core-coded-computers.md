# PREFACE / WHY VIRTUAL CORE CODED COMPUTERS?

## The Convergence of Software Engineering and Hardware Synthesis:

* Hardware and software are two fundamental components of modern computing.
* Hardware gives **life** to Software, Software gives a **purpose** to hardware.
  
* Think of them like this, **Hardware** as a **soil** and **software** as a **fruit**..., Soil (Hardware) gives life to Fruit (software), So that we cannot **EAT (USE)** Soil (Hardware) directly, Just as soil alone is not the final product we seek, hardware alone is rarely useful without software that gives it purpose...
* So there is equal need in softwares as same in hardwares...
* For Decades, Hardware engineers designed hardware, We Can really thank them as they evolved a building sized computers and storage machines into a faster fingertip computers and microchips., On the other side we can also thank Software engineers as they evolved many things we can list out...!
* At first glance, hardware and software may appear to be completely different fields. However, both belong to the broader discipline of computer science and computer engineering, where each depends on the other to create functional computing systems.
* Actually we started combining them using softwares., like Virtual machines / virtual computers using software. Emulators reproduce entire CPUs in code. FPGAs allow hardware to be generated from descriptions written as code. Compilers transform high-level logic into low-level machine operations.
* For me, this convergence was not first discovered in a laboratory or research paper. It began with a simple question while using my own Chromebook.
* My curiosity began when I discovered that my cx1400cka Chromebook could run ChromeOS and Linux simultaneously. At first this seemed impossible. How could one computer behave as if it contained another computer inside it? The answer led me to the world of virtual machines, software-defined systems, and eventually the ideas explored throughout this book.
* If software can describe processors, memory systems, storage devices, operating systems, and even complete execution environments, then the boundary between software engineering and hardware architecture becomes increasingly blurred. VCCC explores this intersection by treating computer architecture itself as something that can be constructed, modified, and studied through code.
* If software can define a processor, memory, storage, and even an operating system, then what truly separates a computer from the code that describes it?
